# GitVerse Feature Inventory & Achievement Catalog

This document provides a comprehensive inventory of all achievements and profile highlights tracked by GitVerse, along with their unlock criteria, tier thresholds, and provenance classification.

---

## 1. Earnable Achievements

Achievements that can currently be unlocked by developers on GitHub:

### 🦈 Pull Shark
* **Description:** Open pull requests that get merged.
* **Tiers:**
  * **x1 (Base):** 2 merged PRs
  * **x2 (Bronze):** 16 merged PRs
  * **x3 (Silver):** 128 merged PRs
  * **x4 (Gold):** 1,024 merged PRs
* **Provenance:** `calibrated` (Counted via GitHub API issues search and calibrated against official milestone records).

### ⭐ Starstruck
* **Description:** Create a repository that earns stars.
* **Tiers:**
  * **x1 (Base):** 16 stars
  * **x2 (Bronze):** 128 stars
  * **x3 (Silver):** 512 stars
  * **x4 (Gold):** 4,096 stars
* **Provenance:** `calibrated` (Measured using the highest star count of any single owned repository).

### 👥 Pair Extraordinaire
* **Description:** Coauthor commits on merged pull requests (`Co-authored-by: Name <email>` in commit messages).
* **Tiers:**
  * **x1 (Base):** 1 coauthored PR
  * **x2 (Bronze):** 10 coauthored PRs
  * **x3 (Silver):** 24 coauthored PRs
  * **x4 (Gold):** 48 coauthored PRs
* **Provenance:** `official` (Extracted from official profile tier records; no public API counting rule).

### 🧠 Galaxy Brain
* **Description:** Have answers accepted in GitHub Discussions.
* **Tiers:**
  * **x1 (Base):** 2 accepted answers
  * **x2 (Bronze):** 8 accepted answers
  * **x3 (Silver):** 16 accepted answers
  * **x4 (Gold):** 32 accepted answers
* **Provenance:** `counted` (Computed via GraphQL user discussion answers telemetry).

### ⚡ Quickdraw
* **Description:** Close an issue or pull request within 5 minutes of opening it.
* **Tiers:** Single Tier (Unlocked or Not).
* **Provenance:** `official`

### 🚀 YOLO
* **Description:** Merge a pull request without an approving code review.
* **Tiers:** Single Tier (Unlocked or Not).
* **Provenance:** `official`

### 💖 Public Sponsor
* **Description:** Sponsor an open-source contributor or organization through GitHub Sponsors.
* **Tiers:** Single Tier (Unlocked or Not).
* **Provenance:** `official`

### 🎨 Finishing Touch
* **Description:** Have pull requests merged that improve the quality of GitHub's UI.
* **Tiers:**
  * **x1 (Base):** 1 PR
  * **x2 (Bronze):** 4 PRs
  * **x3 (Silver):** 16 PRs
  * **x4 (Gold):** 32 PRs
* **Provenance:** `official`
