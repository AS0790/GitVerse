# GitVerse Developer Glossary

| Term | Definition |
| :--- | :--- |
| **Achievement** | A gamified profile recognition awarded by GitHub for developer contribution milestones. |
| **Tier** | The progressive level of an achievement (Base/x1, Bronze/x2, Silver/x3, Gold/x4). |
| **Milestone** | A specific numerical threshold required to unlock a tier (e.g. 128 merged PRs for Pull Shark x3). |
| **Calibration** | The mathematical process of cross-referencing live API metrics against verified historical unlocks. |
| **Calibration Floor** | The minimum threshold guaranteed by an already earned tier, ensuring progress counters never contradict official unlocks. |
| **Dual-Engine** | The architecture unifying the compiled Go CLI and Vercel serverless web application under identical analytical algorithms. |
| **Vitrine Shelf** | The Space Aurora visual card layout displaying badges on horizontal illuminated shelves. |
