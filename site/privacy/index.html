Privacy Policy

Last Updated: November 2026

This Privacy Policy explains what information we collect, how we use it, and the measures we take to protect it. GitVerse respects your privacy and is committed to protecting the information you share while using our GitHub achievement intelligence platform.

Information We Collect

We may collect information that you voluntarily provide when using GitVerse, including:

  • Contact Information: Your name, email address, and any information submitted through our contact forms, community feedback, or GitHub issue discussions.
  • GitHub Profile & Achievement Data: Public GitHub username, profile statistics, earned badges, tier unlocks, and contribution milestones queried exclusively from GitHub's public web and API endpoints.
  • Ephemeral OAuth Tokens: If you choose to check private repository achievement progress via "Sign in with GitHub", a temporary token is held only in memory for a single calculation pass and immediately revoked via GitHub's OAuth revocation endpoint. No token is ever written to disk or database.
  • User Preferences: Your selected theme settings and analytics consent stored strictly in your browser's local storage.

How We Use Your Information

We use collected data solely to compute and visualize accurate GitHub achievement progress:

  • Achievement & Progress Calculation: Parsing public contribution data to compute tier requirements, distance to next milestone, and historical unlocks.
  • Instant Credential Revocation: Immediately destroying and revoking authorization credentials after computing one-off profile reports.
  • Platform Reliability & Performance: Monitoring serverless runtime error codes without associating them with usernames or repositories.

Data Storage & Zero-Retention Policy

GitVerse is built on a privacy-first, zero-retention architecture:

  • No User Database: GitVerse operates without a database for personal user information. We do not store account profiles, passwords, or repository files.
  • Ephemeral Processing: All calculations are executed on-demand in isolated serverless execution environments and wiped upon response delivery.
  • Encrypted Transport: All network communication is enforced over HTTPS with TLS 1.3 encryption.

Cookies & Local Storage

GitVerse does not use tracking cookies. We utilize standard browser local storage solely to remember your UI theme preference (dark/light) and your analytics consent choice. This information remains completely on your local device and is never transmitted to our servers.

Third-Party Services

Our service interacts with the following external providers under strict security guidelines:

  • GitHub (GitHub, Inc.): Used to read badge artwork from GitHub's CDN and fetch achievement milestone metrics.
  • Vercel (Vercel, Inc.): Hosts our serverless endpoints and static edge distribution under standard CDN security policies.
  • Optional Analytics: Google Analytics runs only if explicitly granted via the consent banner. Page titles are sanitized so no usernames or repository identifiers are transmitted.
