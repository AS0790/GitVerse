YOLO

YOLO ("You want it? You merge it.") is a binary achievement granted when you merge a pull request into a default branch without any approving reviews. It reflects direct developer autonomy on repositories where branch protection rules do not enforce peer review.

How to earn it
Merge a pull request without a review

It shows your YOLO tier, when you unlocked it and, where GitHub's data allows, how many more you need for the next tier. You can also track YOLO online or learn how progress is verified in our calculation methodology.

FAQ

How do you unlock the YOLO badge on GitHub?
Open a pull request on a repository where branch protection rules allow merging without reviews, and merge it directly with 0 approvals.
Does having an approving review prevent unlocking YOLO?
Yes. If a pull request receives an approving code review prior to merge, it qualifies as reviewed and will not award the YOLO badge.
