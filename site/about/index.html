About GitVerse

What it is

GitVerse is a free, open source tool that shows every GitHub profile achievement, the tier you hold and how far you are from the next one. It comes as a GitHub CLI extension (gh extension install nmloc/GitVerse, then gh achievements) and as a web checker on this site. Both build the same report from the same code.

Why it exists

GitHub shows the badges you have but not how close you are to the next tier, and its API does not expose achievements at all. GitVerse reads GitHub's own badge pages for tiers and unlock dates, counts progress through the GitHub API, and labels every number official, calibrated or counted so you can tell how sure it is. The methodology page explains each source and its limits.

Who makes it

It is written and maintained by nmloc as an independent project. The source code, issue tracker and release history are public at github.com/TheVicky1/GitVerse. Releases are built by GitHub Actions from tagged commits, and the achievement catalog is checked against live profiles every week.

Not affiliated with GitHub

GitVerse is not made, affiliated with or endorsed by GitHub. Badge artwork belongs to GitHub and is loaded from GitHub's own CDN. The project is released under the MIT license and costs nothing to use.
