About

Built in the open.
For developers.

GitVerse is a free, MIT-licensed tool for anyone who wants to understand their GitHub achievement progress — not just see the badges they already have.

The problem it solves

GitHub shows you which badges you've earned. It doesn't show you how close you are to the next tier, and its public API doesn't expose achievement data at all. GitVerse fills that gap — reading GitHub's own badge history pages for tier thresholds and unlock dates, then counting your progress through the GitHub API.

Every figure in the report is labelled official (read directly from GitHub), calibrated (matched against named milestones) or counted (computed from activity data) — so you always know how reliable a number is.

Two ways to use it

GitVerse ships as a GitVerse CLI (go install github.com/TheVicky1/GitVerse/cmd/gitverse@latest) and as a web tool on this site. Both run the same logic from the same codebase. Use whichever fits your workflow.

Who built it

GitVerse was written and is maintained by nmloc as an independent side project. The source code is public at github.com/TheVicky1/GitVerse. Releases ship from GitHub Actions, and the achievement catalog is re-verified against live profiles each week.

Not GitHub

GitVerse is not affiliated with or endorsed by GitHub, Inc. Badge artwork is GitHub's property and is loaded from their CDN. The project is released under the MIT licence.

Free

MIT licensed

Always free to use. Fork it, self-host it, contribute to it. The source is public and open.

Safe

Zero data retention

No user database. No stored tokens. OAuth credentials are revoked immediately after a single calculation pass.

Live

Weekly verification

The achievement catalog is checked against real GitHub profiles every week to stay accurate as GitHub evolves.
