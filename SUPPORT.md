# Support Guidelines

Need help with **GitVerse**? We are here to support you!

---

## 💬 Community Questions & Discussions
For general questions, feature requests, or brainstorming ideas:
* Open a topic in [**GitHub Discussions**](https://github.com/TheVicky1/GitVerse/discussions).

---

## 🐛 Reporting Bugs
If something is broken, inaccurate, or unexpected:
1. Search existing [Issues](https://github.com/TheVicky1/GitVerse/issues) to see if it has already been reported.
2. If not, open a new issue using our structured templates:
   * [**Bug Report**](https://github.com/TheVicky1/GitVerse/issues/new?template=bug.yml) — Something is broken or threw an error.
   * [**Count Looks Wrong**](https://github.com/TheVicky1/GitVerse/issues/new?template=count-looks-wrong.yml) — A badge tier count differs from GitHub's profile.
   * [**Missing Achievement**](https://github.com/TheVicky1/GitVerse/issues/new?template=new-achievement.yml) — GitHub released a new badge not in our catalog.

---

## 🔒 Security Vulnerabilities
Do NOT report security vulnerabilities through public issues.
Please submit a [Private Security Advisory](https://github.com/TheVicky1/GitVerse/security/advisories/new) or email maintainer **Vicky Patel** directly at **vickybiz55808@gmail.com**.
