# Check your GitHub achievements

Type a username at https://gitverse.vercel.app/check/ for public data, or sign in with GitHub to include private contributions. A public report has a shareable address: https://gitverse.vercel.app/result?u=<username>.

In a terminal: `go install github.com/TheVicky1/GitVerse/cmd/gitverse@latest`, then `gitverse [username]` (add `--json` for machine-readable output).
