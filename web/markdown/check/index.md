# Check your GitHub achievements

Type a username at https://mygitverse.vercel.app/check/ for public data, or sign in with GitHub to include private contributions. A public report has a shareable address: https://mygitverse.vercel.app/result?u=<username>.

In a terminal: `go install github.com/TheVicky1/GitVerse/cmd/gitverse@latest`, then `gitverse [username]` (add `--json` for machine-readable output).

Explore all badge criteria in the [Achievements Directory](https://mygitverse.vercel.app/achievements/) or review our [Accuracy Methodology](https://mygitverse.vercel.app/methodology/).
