# Quickdraw (GitHub achievement)

- Status: Earnable
- How to earn: Close an issue or pull request within 5 minutes of opening it
- Tiers: one tier
- Progress in GitVerse: earned or not (official)

Quickdraw ("Gitty up!") is a binary achievement awarded for closing an issue or pull request within 5 minutes (300 seconds) of its creation. It is commonly unlocked during rapid triage, accidental issue duplication, or automated workflow fixes.

## FAQ

### Can you get Quickdraw by closing your own issue?

Yes. Opening an issue or pull request and manually closing it within 5 minutes triggers the achievement.

### Does Quickdraw have multiple tiers or multipliers?

No. Quickdraw is a single-tier binary unlock with no progressive tier rings.
