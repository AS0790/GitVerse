# Arctic Code Vault Contributor (GitHub achievement)

- Status: Retired (no longer earnable)
- How to earn: Code in a repository of the 2020 GitHub Archive Program
- Tiers: one tier
- Progress in GitVerse: earned or not

Arctic Code Vault Contributor commemorates developers whose public code was captured during the GitHub Archive Program snapshot on February 2, 2020. The archive is preserved on silver halide film in a decommissioned coal mine in Svalbard, Norway, designed to last 1,000 years.

## FAQ

### Is Arctic Code Vault Contributor still earnable?

No. The historical snapshot was taken on 02/02/2020 and cannot be retroactively added to new accounts.

### How was eligibility determined for the Arctic Code Vault badge?

Any developer who authored at least one commit in the default branch of an active public repository captured in the 2020 archive received the badge.
