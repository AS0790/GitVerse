# Finishing Touch (GitHub achievement)

- Status: Earnable
- How to earn: Get pull requests that improve GitHub's UI quality merged
- Tiers: 1 · 4 · 16 · 32
- Progress in GitVerse: official tier (no public counting rule)

Finishing Touch counts merged pull requests classified by GitHub as improving UI and frontend quality. Milestone rings are awarded at 1, 4, 16, and 32 merged contributions that enhance interface polishing.

| Tier | Needed |
|---|---|
| x1 · base | 1 merged UI quality pull requests |
| x2 · bronze | 4 merged UI quality pull requests |
| x3 · silver | 16 merged UI quality pull requests |
| x4 · gold | 32 merged UI quality pull requests |

## FAQ

### How many pull requests do you need for Finishing Touch?

1 merged UI quality pull request for base (x1), 4 for bronze (x2), 16 for silver (x3), and 32 for gold (x4).

### How does GitHub identify UI quality pull requests?

GitHub uses internal heuristics and commit metadata evaluating frontend enhancements, CSS modifications, and linked UI issue resolutions.
